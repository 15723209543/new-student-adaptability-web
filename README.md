# 新生大学适应性调查网页 · 使用说明

## 一、文件目录

```text
问卷项目/
├── main.html                    ← 直接双击打开（离线可用）
├── doc/
│   ├── 板块1：学习方面.md        ← 用户原始题目
│   ├── 板块2：实验室、科研及学科竞赛方面.md
│   ├── 板块3：文体活动参与和生活适应及身心状态方面.md
│   └── 使用说明.md
├── code/
│   ├── app.js                   ← 页面交互、必填判断、导出逻辑
│   ├── styles.css               ← UI 样式
│   ├── questions.js             ← 由原始 Markdown 生成的题目及选项
│   ├── 班级徽标.jpg               ← 用户提供的班徽，替代“26·3”文字图标
│   ├── build_questions.py       ← 重新从原始 Markdown 生成 questions.js（仅修改题目时需要）
│   └── server.go                ← 启动器的 Go 源代码
└── start/
    └── 启动调查问卷.exe          ← Windows 64 位本地启动器
```

## 二、打开方式（二选一）

**方式 A（最简单）**：完整解压 ZIP 后，直接双击根目录的 `main.html`，默认浏览器即可离线填写，无需连接网络。

**方式 B（Windows）**：完整解压 ZIP 后，双击 `start/启动调查问卷.exe`。程序会自动建立**仅允许本机访问**的 `127.0.0.1` 网页地址，并尝试调用默认浏览器打开 `http://127.0.0.1:18726/main.html`。如果端口已被使用，启动器会自动改用其他可用端口，浏览器会自动打开实际端口。若 Windows 弹出安全提示，确认文件来源后自行决定是否运行。启动器长时间没有收到页面活动后会自动退出。

**重要**：保留 `doc`、`code`、`start` 文件夹与根目录 `main.html` 的相对位置；不能只把 EXE 或 HTML 单独复制走。EXE 仅支持 Windows x64，直接打开 HTML 则不受该平台限制。

## 三、页面与必填规则

1. 基本信息：姓名、学号、宿舍号，3 项必填；学号需使用数字。
2. 第一板块（学习方面）：7 题，其中 1—6 题必填。
3. 第二板块（实验室、科研及学科竞赛方面）：7 题，其中 1—6 题必填。
4. 第三板块（文体活动参与和生活适应及身心状态方面）：16 题，其中第 6、15、16 题选填，其他题必填；校园跑次数可填 `0`。
5. 完成页：两个导出按钮，分别导出 CSV 和 TXT。

下一页按钮在必填题全部作答前为**灰底白字且不可点击**；全部作答后自动变成**蓝底白字**，允许下一步。多选题至少选一项，同一题中“暂无”“未参加”“暂无明显问题”等与实际选项互斥。

对于原始 Markdown 中要求的“选择相关选项则显示填写框”，已逐项加上**条件补充说明（必填）**：当该补充框出现时，必须输入至少一个非空白字符才能进入下一页；选择“否”“暂无”“未参加”“全部非常满意”等不触发的选项时隐藏，不再要求填写。刷新、返回修改、切换选项都会实时重新计算本页必填数量，已填写过的内容会被保留；隐藏的说明不会参与导出。

## 四、首页说明及图标

首页说明已根据 2026-10-26 最新文案修改，涵盖三个调查目的与保密提示；顶部的 26·3 文字图标已经替换为用户提供的班级徽标图片，图片文件位于 `code/班级徽标.jpg`。

## 五、导出文件说明

- **CSV 文件**：UTF-8 BOM 编码，适合 Excel/WPS 打开。第 1 行为 33 个列标题（姓名、学号、宿舍号和 30 道问卷题），第 2 行为该同学的 33 个答案。**一人一行、一题一格**，所有多选答案、说明文本都留在本题的唯一单元格中。
- 选择题如果有填写说明，则保存为 `（选项1；选项2）：（补充填写内容）`，内容含逗号、引号或换行时仍保留在同一个 CSV 单元格；为了确保一位同学的数据始终占据一行，填写的换行会转换为 ` / `。
- **TXT 文件**：按身份信息、第一板块、第二板块、第三板块依次输出，每一题保留题干和对应答案。
- 两种文件均在填写同学的设备上**下载到本地**；网页没有问卷提交接口、数据库、自动收集或上传功能。若需要集中汇总，请由收集人另行统一收齐导出的文件。请妥善保管包含姓名、学号和宿舍号的文件。
- 页面在同一浏览器标签页中刷新时可尝试恢复填写进度；关闭标签页或在不同打开方式间切换时，**不保证保留进度**。请填写完及时保存。

## 六、维护

如果修改 `doc` 中原始 Markdown，需在项目根目录执行（仅开发时需要）：

```bash
python code/build_questions.py
```

使用页面或 EXE 不依赖 Python。源码位于 `code/`，所有界面资源都是本地文件，不依赖外部字体或第三方 CDN。
